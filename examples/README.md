# Экспортированные демонстрационные SVG

## Текущее состояние

Папка содержит три композиции, экспортированные через существующий редактор Forma. Они используют только объекты из `public/assets/manifest.json` и сохраняют редактируемые векторные path, слои и трансформации.

## Включённые файлы

- `initial.svg` — 1280 × 720, 3 слоя;
- `music.svg` — 1280 × 720, 5 слоёв;
- `tecnologies.svg` — 1280 × 720, 6 слоёв.

## Как проверить

1. Запустите `npm run dev` и откройте Forma.
2. Откройте файл из этой папки в браузере или векторном редакторе.
3. Проверьте отдельные `<g>`-слои с `data-asset-id` и исходные `<path>` внутри них.
4. При необходимости загрузите соответствующий preset в Forma и повторите экспорт кнопкой **Export SVG**.

Файлы не содержат `<image>`, `foreignObject`, скриптов или внешних ссылок.
