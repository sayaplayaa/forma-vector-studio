# Экспортированные демонстрационные SVG

## Текущее состояние

В исходном проекте есть три проверенных демонстрационных preset в `src/data/examples.ts`, но готовых экспортированных SVG-файлов в рабочей папке не найдено. Эта папка намеренно не содержит выдуманных или заново нарисованных примеров.

## Ожидаемые файлы

После ручного экспорта положите сюда:

- `ideas-that-connect.svg`;
- `a-calmer-workspace.svg`;
- `on-the-same-wavelength.svg`.

## Как экспортировать

1. Запустите `npm run dev` и откройте Forma.
2. Выберите соответствующую demo-композицию над холстом.
3. Нажмите **Export SVG**.
4. Сохраните полученный файл под указанным выше именем в папку `examples/`.

Экспорт выполняется самим редактором и сохраняет исходную векторную геометрию, слои и трансформации.
